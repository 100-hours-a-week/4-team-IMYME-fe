# MINE - 내 손안의 AI CS 튜터

드디어 개발자 면접 준비의 필수 파트너, **MINE**
이제 눈으로만 보지 말고, **직접 말하면서** CS 지식을 내 것으로 만들어보세요.

---

### ✨ 주요 기능

**🗣️ 말하면서 배우는 '레벨업 모드'**

- CS 개념을 내 목소리로 설명하면, AI가 실시간으로 듣고 피드백을 해줘요.
- "이 부분은 설명이 부족해요", "정확한 비유네요!" 같은 1:1 과외를 받아보세요.

**⚔️ 대결하며 배우는 ‘PvP 모드’**

- 상대와 1:1 매칭 후, 주어지는 랜덤 키워드에 대해 설명해보세요.
- 대결의 승패와 비교 피드백을 통해 CS 개념 지식 점검을 해보세요.

**💡 도전하며 배우는 ‘챌린지 모드’**

- 매일 오후 10시에 오픈되는 챌린지에 참가하여 주어진 키워드에 대해 설명해보세요.
- 오후 11시에 공개되는 랭킹을 통해 나의 지식 수준을 확인하시고 챔피언을 노려보세요!

---

**🧠 나만의 지식 지도**

- 단순 암기는 그만! 연관된 개념을 꼬리에 꼬리를 물고 추천해 드려요.
- 내가 학습한 내용이 시각화되어 지식이 쌓이는 걸 볼 수 있어요.

**⚡ 3초 만에 시작하는 간편 로그인**

- 복잡한 가입 없이 **카카오톡**으로 바로 시작하세요.
- PC, 태블릿, 스마트폰 어디서든 내 학습 기록이 연동됩니다.
